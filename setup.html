Installation Guide

1

Download Extension

Download MoodleGPT 3 from the Chrome Web Store. It costs a subscription of 5€ every 2 months to unlock all features.

2

Get API Key

Go to Google AI Studio and generate a free API Key. Supported models include Gemini 3.0 Pro Preview, Gemini 2.5 Pro, and Gemini 2.5 Flash.

Get Free Key
3

Configure & Activate

Click the extension icon, paste your API Key in settings, and click "Validate". You are now ready to solve quizzes.
